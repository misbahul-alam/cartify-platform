# 🛒 Cartify Platform

A production-oriented backend service for an e-commerce platform, built with Go.

This repository is currently in bootstrap stage and has the Go module initialized.

---

## 🚀 Tech Stack

- **Language:** Go
- **Framework:** Gin
- **ORM:** GORM
- **Database:** PostgreSQL, Redis

## 📖 API Documentation

The API documentation is provided by Swagger.

### Accessing Swagger UI

Once the server is running, you can access the Swagger UI at:
`http://localhost:8080/swagger/index.html`
